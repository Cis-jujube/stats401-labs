# Lab 3: Web Data Acquisition

This assignment uses HTML scraping, one of the two methods in
[the Lab 3 handout](https://github.com/hiilab/stats-401/blob/main/Lab3.md).

## Files

- `scrape_example.py`: requests 50 book catalogue pages, with a one-second delay,
  a ten-second timeout, and basic error handling.
- `../data/lab3_data.csv`: 1,000 book records generated by the Python script.
- `index.html`: describes the dataset and contains the HTML table.
- `lab3.js`: loads the CSV with D3 and sorts each column in both directions.
- `lab3.css`: simple table borders, spacing, and horizontal scrolling on small screens.

The five columns are `id`, `title`, `price_gbp`, `rating`, and `availability`.
The ID comes from the source's book URL. Ratings range from 1 to 5.
Prices are in British pounds. These are fictional bookstore sample records,
not current retail prices or verified reader reviews.

## Run the script

Use a Python environment with `requests`, `beautifulsoup4`, and `pandas` installed,
as described in Task 1. From the repository root, run:

```bash
python lab3/scrape_example.py
```

On this Mac, the existing Python 3.13 environment already has those packages:

```bash
/opt/homebrew/Caskroom/miniconda/base/bin/python lab3/scrape_example.py
```

No new packages or global settings were needed. The tested library versions are
requests 2.33.1, beautifulsoup4 4.15.0, and pandas 3.0.5.
The script saves only after it has checked for 1,000 distinct book IDs.
If a request or record fails, it stops without replacing an existing dataset.
Do not rerun it unnecessarily; the saved CSV is sufficient for viewing the page.

## Responsible collection

Sources reviewed on September 3, 2026:

- [ToScrape](https://toscrape.com/) explicitly describes Books to Scrape as a
  safe scraping practice site, with 1,000 items and up to 20 items per page.
- [Books to Scrape](https://books.toscrape.com/) provides public sample book data.
- [robots.txt](https://books.toscrape.com/robots.txt) returned HTTP 404.
  A missing robots file is not permission by itself; the ToScrape sandbox
  description is the permission basis for this class exercise.

The script uses an informative user agent and requests only catalogue pages,
one at a time. It does not access accounts, private data, or book-detail pages.
HTTP errors, including 403 and 429, stop the script rather than trigger retries.
Review the source rules again before collecting a new copy.

## View and publish

From the repository root, start a local static server:

```bash
python -m http.server 8000 --bind 127.0.0.1
```

Open `http://127.0.0.1:8000/lab3/`. Stop the server with Control-C.
The page displays every record. Click a heading once for ascending order and
again for descending order; numeric columns sort as numbers.
Python runs separately from the webpage. GitHub Pages reads the saved CSV.

The handout also requires committing the Python script and dataset, publishing
the page through GitHub Pages, and submitting one direct `/lab3/` Pages link.
Local testing does not complete those publication or submission steps.
