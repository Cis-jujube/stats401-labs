Dataset

This lab uses a synthetic city transit network with 50 stations and 50 routes. The stations are the nodes, and the direct routes between stations are the links. Each route is undirected, so it can be read in either direction. The short label s1 means Station 1, s2 means Station 2, and so on.

Source: STATS 401 Lab 5. Data: Stations CSV | Routes CSV.

Node-Link Design Justification

District colors show membership; circle area represents passenger volume. Thin, thick, and dashed borders distinguish Local, Transfer, and Terminal stations. Route colors distinguish services. Thicker lines make longer journeys noticeable. Dragging separates overlaps; highlighting reveals neighbors; tooltips give exact values. Positions are not geographic.

Adjacency Matrix

Both axes list all 50 stations, sorted by district and then station number. A colored cell shows a direct route between its row and column stations. A light gray cell means there is no direct route. Hover over a cell to see the station pair, travel time, and route type.

Travel time: cell opacity

Route colors match the line-color legend above. Darker cells mean longer travel times.

Matrix Design Justification

Rows and columns use the same district order, then station number, so district blocks reveal connections. Label colors identify districts. Cell hue represents route type; darker cells mean longer travel times. Gray means no direct route. The undirected matrix is symmetric.

Network Questions

  1. Which stations appear central? Partially, using node-link highlighting: Stations 7, 18, and 29 each have three neighbors, tied with others for the maximum. No unique degree hub stands out; screen position alone is insufficient.

  2. Which districts are strongly connected? Well, using matrix blocks: East–South has the most direct routes (11), followed by Central–North and East–West (nine each). Count one symmetric block per pair.

  3. Where are Transfer and Terminal stations? Well, using node-link borders and highlighting: Transfer 50 has one neighbor; Terminal 7 has three, while Terminal 49 is isolated. These labels do not guarantee endpoints.

  4. Which stations have high passenger volume? Well, using node-link sizes and tooltips: Stations 50, 49, and 48 are largest, with 9,850, 9,677, and 9,504 passengers.

  5. Where are the longest direct journeys? Well, using thick node-link lines and tooltips: 7–31 takes 16 minutes, 18–34 takes 15, and 29–50 takes 14; all are Express.

  6. Are route types concentrated? Partially, using matrix colors: services mix across district blocks. Both within-Central connections are Shuttle, but no large service-specific cluster is evident.
